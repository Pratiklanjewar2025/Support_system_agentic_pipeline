🏛️ AdaRAG-Ops: System Architecture & Workflow

High-level end-to-end architecture showing Pre-LLM Cache Guard, FAISS RAG, 4-Tier Adaptive Router, and Verification Feedback Loops.

Figure 1: Complete Component Architecture of AdaRAG-Ops Multi-Agent SRE Support Pipeline
⬇️ Download Architecture Diagram (HD JPG)
Pillar 1: Pre-LLM Cache Guard
⚡ Instant 0-Cost Bypass (<20ms)
Checks SQLite persistent cache using SHA-256 exact matching and local SentenceTransformer semantic embeddings. Verified solutions are served immediately with 0 LLM calls and $0.00 cost. Context guards prevent dangerous false matches.
Pillar 2: FAISS Vector RAG
📚 Evidence-Grounded Context Retrieval
Embeds technical runbooks, SRE playbooks, and incident postmortems into a FAISS dense vector index. Computes retrieval confidence, coverage, and flags missing telemetry items before diagnosis.
Pillar 3: 4-Tier Adaptive Router
🎛️ Pareto-Optimal Model Selection
Dynamically routes queries across 4 capacity tiers: OpenRouter 550B ($0.00), Groq 20B (<0.6s), Gemini 2.5 Flash, and Cohere Command-R+ 104B, optimizing cost and latency without sacrificing reasoning power.
Pillar 4: Claim Verification & Loops
🛡️ Safety Guards & Re-Retrieval Loops
Validates diagnostic claims against evidence. If confidence is low, it executes RETRIEVE_MORE or SWITCH_MODEL. High-risk destructive commands or L3 outages are automatically halted and escalated to human SREs.
